# 🏠 Hostel Complaint & Maintenance System

A simple web-based system to streamline reporting and resolving issues in hostels, built for students and staff.

## 🚀 Features
- Student login & complaint submission
- Categories (Plumbing, Electricity, Cleaning)
- Complaint tracking with timestamps
- Admin dashboard with filter & search
- Update complaint status (Pending → In Progress → Resolved)
- Works offline using localStorage (for GitHub demo)

## 🛠 Tech Stack
- HTML, CSS, JavaScript
- LocalStorage (for demo)
- Firebase (planned for real-time version)
